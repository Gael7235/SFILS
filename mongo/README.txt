# MISFILS
MISFILS: The MongoDB-based Implementation for the San Francisco Integrated Library System.

This folder contains the submission files for Assignment 2. The remaining folders contain the files from Assignment 1.

Make sure to keep all your Assignment 2 files inside this folder to keep the rest of the folders free from clutter. That way, it will be easier to grade both Assignment 1 and Assignment 2.


Create the database in MongoDB Compass, name the connection SFPL_Connection, the database SFPL_DB, and the collection SFPL_Table.
Then import the data from the csv file made from the SFPL DB Excel sheet. First create the csv by saving a copy of the original excel sheet as a csv file, then import that into your collection in MongoDB.
Make sure that the data values look correct and the data types are also correct. Make sure to also uncheck the "Ignore empty strings" option, as the excel sheet has some empty values in it.
Follow instructions on the MongoDB C++ Driver website instructions to run the code.
